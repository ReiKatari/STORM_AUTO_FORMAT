<h1 align="center">STORM AUTO FORMAT</h1>

## **О проекте**
**STORM AUTO FORMAT** — современное десктопное приложение для операционных систем Windows, предназначенное для автоматической фоновой конвертации и экспорта файлов Google Таблиц (`.gsheet` и веб-ссылок Google Sheets) в полноценный формат Microsoft Excel (`.xlsx`) с сохранением 100% исходного визуального оформления, шрифтов, цветов ячеек, формул, границ и объединённых диапазонов.

Приложение спроектировано для непрерывной фоновой работы в системном трее Windows, поддерживает гибкую настройку расписания выгрузки (по временным интервалам или точным часам суток), автоматический запуск при входе в систему и безопасную атомарную перезапись целевых файлов без блокировок и сбоев.

## **Происхождение и архитектура**
Оригинальная архитектурная разработка на базе платформы **Microsoft .NET 8 (WPF)**, системных интерфейсов **Windows Shell / System Tray NotifyIcon**, **Win32 DWM (Desktop Window Manager)** и серверного движка экспорта **Google Sheets API**.

## **Технологический стек**
- **Языки программирования**: C# 12 (.NET 8.0 Windows Desktop SDK)
- **Графический стек**: Windows Presentation Foundation (WPF), XAML, Dark Modern UI Theme, Hardware Accelerated DWM Rendering
- **Системные интерфейсы**: Windows Forms NotifyIcon Integration, Win32 Registry API (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`), Windows Interop DWM API (Immersive Dark Mode TitleBar)
- **Сетевой движок и форматирование**: `System.Net.Http.HttpClient` с поддержкой GZip/Deflate, потоковый экспорт Google Sheets в OpenXML `.xlsx`, `System.Text.Json` парсинг метаданных `.gsheet`

## **Ключевые возможности**
- **100% сохранение форматирования**: Прямая конвертация через движок Google Spreadsheets гарантирует точное сохранение стилей, шрифтов, заливок, числовых форматов, выравнивания, формул и многостраничной структуры.
- **Поддержка файлов .gsheet и прямых ссылок**: Автоматическое извлечение `doc_id` как из локальных JSON-файлов `.gsheet` (Google Drive Desktop), так и из прямых ссылок любого формата (`/d/{id}/edit`, `?id={id}`).
- **Два режима автоматической выгрузки**:
  - *По интервалу*: регулярное обновление каждые $N$ минут (1 мин, 5 мин, 15 мин, 30 мин, 60 мин или произвольное значение).
  - *По точным часам*: ежедневная выгрузка строго в указанное время суток через запятую (например, `09:00, 14:00, 18:00`).
- **Стильный интерфейс и системный трей**: Сворачивание в область уведомлений Windows (системный трей), быстрый запуск конвертации из контекстного меню, обратный отсчет до следующего обновления.
- **Предотвращение дублирования окон**: Защита через глобальные системные мьютексы (`Mutex` и `EventWaitHandle`) с автоматическим восстановлением окна при повторном запуске.
- **Безопасная атомарная перезапись**: Запись во временный буферный файл с последующей заменой целевого `.xlsx` исключает повреждение данных при сбоях сети или выключении питания.
- **Поддержка приватных таблиц**: Возможность указания авторизационных заголовков Cookie / Session Token для таблиц с ограниченным доступом Google Workspace.

## **Установка и запуск**
1. Перейдите в раздел **Releases** репозитория на GitHub.
2. Скачайте актуальную версию инсталлятора `STORM_AUTO_FORMAT_<версия>_Setup.exe` или архив `STORM_AUTO_FORMAT_<версия>.zip`.
3. Запустите инсталлятор или распакуйте архив и запустите `StormAutoFormat.exe`.
4. Укажите путь к файлу `.gsheet` или вставьте ссылку на Google Таблицу, выберите файл назначения `.xlsx` и задайте желаемое расписание.
